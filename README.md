Просто откройте файл index.html 

Все возможные команды реализованы, НО, если что, в чат боте имя можно вводить не только через команду, например, псоле старта, бот скажет как его зоввут и спросит уже ваше имя - достаточно будет написать имя без каких либо спец символов, хз зачем я это добавил (но можно и через команду, так что условие вроде выполнено)

Список команд (на всякий): 
/start
/name: ...
/numbers:
/set: x = ...
/stop
/undo 
Ну и там операции в соответствии с условиями, плюсом есть управление с клавиатуры на стрелочки и enter при отправке сообщения боту
